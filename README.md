GABINETE DIGITAL — MVP PARA TESTE HOJE

Funciona no navegador e como PWA quando publicado em HTTPS. Inclui cadastro, CPF, SUS, mãe, cidade, raça/cor, nacionalidade, bairro, referência, demandas/procedimentos, status, agenda, aniversários e botão de WhatsApp com mensagem pronta, além de impressão.

ATENÇÃO: esta edição salva dados no navegador/localStorage. Não usar com dados reais sensíveis em produção. A versão online de produção precisa de autenticação, banco em nuvem, armazenamento protegido e regras de acesso.
